# 隐私说明

本仓库是**脱敏发行版**，不含任何真实个人数据。

## 已移除的内容

| 类别 | 说明 |
|---|---|
| 原始运动数据 | 不含任何真实 GPX / TCX / CSV 文件 |
| 个人身份 | 不含姓名、账号、平台用户名；导出文件内的姓名标签也已移除 |
| 位置信息 | 不含真实球场名称与经纬度；示例坐标为虚构值 |
| 平台登录流程 | 不含任何平台账号登录、网页抓取或自动导出的脚本 |
| 截图与留档 | 不含登录页、日历页、个人资料页等任何账号相关截图 |
| 一次性脚本 | 早期用于处理个人标定的临时脚本未包含 |

## 示例数据如何生成

`tools/make_sample_data.py` 用随机过程合成一名中前卫/前腰的 100 分钟跑动（含中场休息、冲刺爆发、心率漂移），坐标固定在虚构位置 **30.000000, 120.000000**，场地由脚本自己登记为「示例球场（合成数据）」。

## 你的数据会去哪

整个流程**全本地运行**，不发送任何网络请求（交互式地图只从浏览器加载公开的卫星瓦片）。分析产出写在本地的 `output/`、`report/` 与归档目录。

## 发布到社交平台前建议检查

1. 截图里是否出现真实球场名 / 经纬度 / 账号名
2. 导出文件的文件名是否包含个人信息
3. 心率等健康数据是否愿意公开
